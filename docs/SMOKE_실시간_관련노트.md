# 실시간 관련 노트 — 라이브 스모크 절차

마이크 실녹음으로 "회의 중 관련 노트가 뜨고, 종료 후 근거와 함께 남는지"를 확인하는 절차.
자동 테스트(`pytest`)는 검색·표시·누적 로직만 검증하므로, 실제 마이크·인덱스·화면은 이 절차로 본다.

소요 5~10분. 준비: 노트 폴더(볼트) 설정 + 인덱스 빌드 + OpenAI 키.

## 0. 사전 준비 (1회)

```powershell
python run_meeting.py reindex          # 볼트 .md → data/vault_index.json (섹션 인덱스 포함)
```

- `[설정] → 노트 폴더`가 비어 있으면 검색은 `no_vault` 사유로 비활성된다(의도된 동작).
- 인덱스가 없으면 `index_missing` 배지가 뜬다 → 위 `reindex` 실행.
- 볼트에 논문/이론 노트가 있으면 `wiki.realtime_paper_dirs` 폴더명과 실제 폴더명이 같은지 확인.

## 1. 웹 UI 녹음 (기본 경로)

1. `webUI_실행.bat` (배포본은 `MeetingMinutes.bat`) → 녹음 화면.
2. 상단에 **관련 노트** 바가 보이는지 확인(녹음 시작 전에는 빈 바 또는 사유 배지).
3. 녹음 시작 후, 볼트에 실제로 있는 주제를 **한국어로** 20~30초 말한다.
   - 3세그먼트마다 검색되므로 보통 20~40초 안에 첫 칩이 뜬다.
   - ✅ 기대: `📄 [[노트#섹션]]` 칩이 뜨고, 논문 노트는 `🎓`로 표시된다.
   - ✅ 기대: 칩이 새로 떠도 **전사 본문이 위아래로 밀리지 않는다**(팝업·소리·포커스 이동 없음).
4. `근거 보기`를 눌러 섹션경로 · 관련도(score) · 일치유형 · snippet · 발화가 보이는지 확인.
5. **영어로** 같은 주제를 말해 한국어 노트가 뜨는지 확인(교차언어 — 임베딩 경로).
   - `wiki_knowledge.embedding_enabled=true`이고 `reindex`로 임베딩이 빌드돼 있어야 한다.
6. 정지 → 회의록 생성 완료까지 대기.
7. 회의 상세에서 확인:
   - **회의록** 탭 말미에 `## 🔗 관련 노트` 섹션(링크 + 관련도 + 참조 횟수).
   - 문서 카드 아래 **참조된 관련 노트** 카드 → 펼치면 근거·발화·경로. 제목 클릭 시 지식 그래프로 이동.
   - 회의를 2건 이상 처리하면 같은 카드 하단에 **최근 회의에서 자주 참조된 노트**(교차 집계) 칩.

## 2. 터미널 CLI 녹음

```powershell
python run_meeting.py realtime --topic "양자컴퓨팅 로드맵"
```

- ✅ 기대: 시작 시 `[Wiki] 실시간 관련 노트 검색 활성 (내부자료 우선 — 섹션·논문 노트 포함)`.
- ✅ 기대: 발화 중 `📎 관련: 🎓 [[노트#섹션]] (1.42) · …` + 다음 줄에 노트 경로.
- ✅ 기대: 비활성이면 `[Wiki] 실시간 관련 노트 검색 꺼짐 — <사유>` 가 한 번 출력된다.
- 종료 후 `  실시간 관련 노트 병합: N개 (근거 M건)` 로그와 회의록의 `## 🔗 관련 노트` 확인.
- **실시간 웹 보완은 웹 UI 전용** — CLI는 내부 노트 검색만 한다(설계상 의도).

## 3. 문서유형·전사 무영향 확인

- `meeting` / `seminar` / `lecture` 세 유형 모두에서 동작한다(문서유형 게이트 없음).
- 검색이 켜진 상태와 꺼진 상태의 전사 표시 지연이 체감상 같아야 한다(검색은 별도 스레드풀).
  이상하면 `wiki.realtime_search_interval`을 늘려(예: 5) 재확인.

## 4. 실패 시 진단 순서

| 증상 | 확인 |
|---|---|
| 바에 `검색 꺼짐 — 노트 폴더…` | `[설정]`에서 노트 폴더 지정 |
| 바에 `검색 꺼짐 — 검색 인덱스…` | `python run_meeting.py reindex` 또는 `[설정] → 인덱스 재빌드` |
| 칩이 아예 안 뜸(사유도 없음) | `[설정] → 기능 토글 → 실시간 관련 노트 검색` ON 여부, 발화가 볼트 내용과 겹치는지 |
| 영어 발화로 한국어 노트가 안 뜸 | `wiki_knowledge.embedding_enabled` + `reindex`로 임베딩 빌드 여부(API 키 필요) |
| 회의록에 `🔗 관련 노트`가 없음 | 검색 결과가 0건이었는지(위 항목), 회의록 자체가 생성됐는지 |
| 상세에 카드가 없음 | 서버(웹) 경로로 녹음했는지 — 프런트 단독/모바일 직접 연결 경로는 사이드카를 쓰지 않는다 |
