# AI Minutes 재설계 — 기능 커버리지 매트릭스 v1

실제 컴포넌트 코드(Recorder 108KB · Settings 55KB · SessionDetail 38KB · Assistant/PrepBrief/WikiAsk/Graph/Onboarding/Facilitation/Upload/Text/Dashboard/Cost 등)를 전수 정독해 추출한 전 기능을, 새 IA(라이브러리 · 새로 만들기 · 회의 상세 · 지식 · 준비/비서 · 설정)에 매핑한 표입니다. **"빠진 기능 없음"을 보장하기 위한 기준 문서**이며, 이후 PRD의 수용 기준으로 사용합니다.

## 범례
- ✅ **유지** — 개념·위치 그대로
- ↔ **이동** — 다른 화면으로 옮김(기능 동일)
- ⚠ **명시적 배치 필요** — 기능은 유지하되 현재 프리뷰 v0.2에 아직 안 그려짐 → 다음 시안에서 반드시 자리 잡아야 함
- 🔧 **평문화** — 기술용어/구현 노출은 숨기되 기능·표시는 유지
- ❗ **결정 필요** — 위치·표현을 사용자와 합의해야 함
