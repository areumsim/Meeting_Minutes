========================================================
  회의록 자동 생성기 (Meeting Minutes) — 사용 설명서
========================================================

이 프로그램은 회의/세미나 오디오를 자동으로 글로 옮기고(STT),
회의록·요약·액션아이템을 만들어 줍니다. 원하면 Obsidian 볼트(.md 폴더)에도
정리해 쌓아두고, 지난 기록을 근거로 질문에 답하거나(위키) 회의 준비
브리핑을 만들 수 있습니다.

※ 이 버전은 "설치가 필요 없는 포터블 방식"입니다. 폴더 안에 파이썬 실행기가
  함께 들어 있어, exe 를 쓰던 예전 방식보다 처음 실행이 훨씬 빠릅니다
  (백신 검사에 걸려 오래 걸리던 문제 해소).


########################################################
1. 실행 방법
########################################################

1) 받은 압축파일(MeetingMinutesPortable.zip)을 원하는 폴더에 전부 풉니다.
   (예: 바탕화면\MeetingMinutes)
   ★ 반드시 zip 을 "전부" 풀어서 쓰세요. zip 안에서 바로 실행하면 안 됩니다.
   ※ 사내망/인터넷으로 받은 zip은 "차단" 표식이 붙어 실행이 막힐 수 있습니다.
     압축 풀기 전에 zip 파일 우클릭 → 속성 → 하단의 "차단 해제(Unblock)"에 체크 →
     [확인] 한 뒤 압축을 풀면 SmartScreen/보안 경고를 예방할 수 있습니다.
2) 폴더 안의 "MeetingMinutes.bat" 를 더블클릭합니다.
3) 잠시 뒤 웹 브라우저가 자동으로 열립니다.
   ※ 실행하면 검은 창이 잠깐 떴다 사라지는 것은 정상입니다
     (서버는 창 없이 백그라운드로 계속 실행됩니다).
   - 안 열리면 브라우저에 http://localhost:8501 을 직접 입력하세요.
     (8501 포트가 이미 쓰이는 중이면 프로그램이 다른 포트를 자동 선택합니다.
      이때는 자동으로 열린 브라우저 주소를 그대로 쓰거나, 종료 후 다시 실행하세요.)
4) 종료: 웹 화면 좌측 하단 [설정] → 맨 아래 "앱 종료" 버튼을 누릅니다.
   (또는 작업 관리자에서 "pythonw" / "python" 프로세스를 종료)

※ 이 프로그램은 "이 폴더 안의 MeetingMinutesData" 에만 설정·회의록을 저장합니다.
  같은 PC 에서 다른 방식(개발용 소스 실행)으로 쓰던 설정과는 **별개**입니다. 그래서 처음
  실행하면 API 키·노트 폴더가 비어 있는 것이 정상이며, 여기서 다시 입력하면 됩니다.
  (설정이 사라진 것이 아닙니다 — 어느 폴더를 쓰는 중인지는 [설정] → "Obsidian 전체 진단"
   의 "데이터 폴더" 줄에서 확인할 수 있습니다.)

※ 실행이 안 되거나 브라우저가 안 열릴 때: "Troubleshoot.bat"(문제 진단용 콘솔) 을 대신
  더블클릭하면 검은 창에 진행/오류 메시지가 그대로 보여 원인 파악에 도움이 됩니다.


########################################################
2. 최초 설정 — API 키 발급 (처음 한 번만)
########################################################

★ 처음 실행하면 "설정 마법사"가 자동으로 뜹니다. 화면 안내를 따라
  ① OpenAI 키 ② 저장 폴더 ③ (선택)Obsidian 볼트 ④ (선택)이메일 을
  순서대로 넣으면 준비가 끝납니다. 나중에 [설정] 우측 위 "설정 마법사
  다시 열기" 버튼으로 언제든 다시 실행할 수 있습니다.

아래는 마법사를 건너뛰고 [설정] 화면에서 직접 입력할 때의 안내입니다.
입력한 키는 이 PC 안(config.json)에만 저장되고 화면에서는 ●●●로 가려집니다
(눈 아이콘으로 잠깐 볼 수 있습니다). 저장 후 [OpenAI 연결 테스트] /
[Claude 연결 테스트] 버튼으로 확인하세요.
설정 화면은 자주 쓰는 항목만 펼쳐져 있고, 나머지는 "고급 설정" 아래에
접혀 있습니다. 필요할 때 제목을 눌러 펼치세요.


─────────────────────────────────────────
 (1) OpenAI API 키   ← 필수 (음성 인식 + 회의록 생성)
─────────────────────────────────────────
  1. 웹브라우저에서 https://platform.openai.com/api-keys 접속
  2. OpenAI 계정으로 로그인 (없으면 회원가입)
  3. 오른쪽 위 [+ Create new secret key] 클릭
  4. 이름 아무거나 입력 → [Create secret key]
  5. "sk-proj-..." 로 시작하는 키가 딱 한 번만 표시됩니다.
     → [Copy] 눌러 복사 (이 창을 닫으면 다시 볼 수 없음!)
  6. 프로그램 [설정] → "OpenAI API 키" 칸에 붙여넣기 → [설정 저장]
  ※ 사용하려면 결제수단 등록이 필요할 수 있습니다:
     https://platform.openai.com/account/billing
     (요금은 사용한 만큼 과금. 회의 1건 처리 비용은 보통 수백 원 수준)
  ★ 이 키 하나면 모든 기능(음성 인식·회의록·번역·위키)이 동작합니다.
     아래 (2) Claude 키는 넣지 않아도 됩니다.


─────────────────────────────────────────
 (2) Anthropic(Claude) API 키   ← 선택 (Claude로 회의록 생성 시)
─────────────────────────────────────────
  1. https://console.anthropic.com/settings/keys 접속
  2. 로그인 → [Create Key]
  3. 이름 입력 → 생성 → "sk-ant-..." 키 복사 (한 번만 표시)
  4. [설정] → "Anthropic API 키" 칸에 붙여넣기 → [설정 저장]
  ※ [설정] → 모델 → "회의록 생성 AI" 를 "Claude"로 바꿔야 사용됩니다.
  ※ 요금/크레딧: https://console.anthropic.com/settings/billing
  ※ Claude를 선택했는데 키가 없거나 잘못됐으면 자동으로 GPT(OpenAI)로
     대체 생성되므로 회의록이 멈추지는 않습니다.


─────────────────────────────────────────
 (2-1) 음성 인식이 멈추지 않게 하는 백업   ← 선택(권장)
─────────────────────────────────────────
  OpenAI 쪽 장애·키 문제·사내망 차단으로 음성 인식이 실패하면 회의 기록이
  아예 남지 않습니다. 그때를 대비한 백업이 두 가지 있습니다.

  ① Groq 키 (다른 회사의 음성 인식) — 무료로 발급되고, 평소엔 쓰이지 않습니다.
     1. https://console.groq.com/keys 접속 → 로그인 → 키 생성
     2. "gsk_..." 키 복사 → [설정] → "Groq API 키" 칸에 붙여넣기 → [설정 저장]
     → OpenAI가 실패한 구간만 자동으로 Groq로 넘어가고, 화면에 한 번 알려 줍니다.
     ★ 실시간 녹음에도 적용되는 백업은 이것 하나입니다. 꼭 넣어 두세요.

  ② 이 PC 안에서 도는 백업(인터넷이 아예 안 될 때)
     1. [설정] → "고급 설정" → "오디오 전처리" 를 펼칩니다.
     2. [로컬 백업 모델 준비] 버튼을 누릅니다(수십~수백 MB 다운로드, 1~3분).
        ★ 회의 중에는 절대 내려받지 않습니다. 미리 눌러 두세요.
        (준비 안 된 상태로 두면 이 백업은 그냥 건너뛰어집니다)
     3. 같은 화면의 "로컬 STT 최종 백업"을 켭니다.
     → 인터넷·API가 모두 죽어도 이 PC가 전사합니다. 단, 컴퓨터 성능에 따라
       실제 녹음 길이의 1~3배 시간이 걸리고 정확도는 OpenAI보다 낮습니다.
     ★ 적용 범위: "파일 올려서 처리하기" 와 "폴더 자동 감시" 입니다.
       실시간 녹음 화면에는 적용되지 않습니다(느려서 실시간을 못 따라갑니다).
       인터넷이 완전히 끊긴 상태로 실시간 녹음을 하면 기록이 남지 않으니,
       그럴 때는 휴대폰 등으로 녹음한 뒤 그 파일을 올려서 처리하세요.


─────────────────────────────────────────
 (3) Obsidian 볼트 폴더   ← 선택 (회의록을 Obsidian에 쌓고 싶을 때)
─────────────────────────────────────────
  ★ 가장 쉬운 방법: 그냥 .md 파일이 든 "폴더 경로"만 지정하세요.
    - [설정] → "Obsidian 볼트 폴더" 옆 [찾아보기] 버튼으로 폴더를 고르거나
      경로를 직접 입력 (예: D:\Obsidian\MyVault)
    - [Obsidian 경로 확인] 버튼으로 존재 확인
    - 노트를 추가/변경했으면 [검색 인덱스·그래프 재빌드] 를 눌러 최신화
      (검색 목록과 [지식그래프]를 함께 최신화합니다)
    → 이 상태만으로도 [위키 질문], [회의 준비] 기능이 폴더의 .md 를
      근거로 동작합니다. (아래 (4) REST API 없이도 됩니다)

  ※ Obsidian은 "선택"입니다. 폴더를 안 넣으면 결과가
     MeetingMinutesData\output\ 안에 파일로만 저장됩니다.


─────────────────────────────────────────
 (4) Obsidian Local REST API 키   ← 고급/선택
─────────────────────────────────────────
  회의록을 Obsidian 앱에 실시간으로 "직접 써넣고" 싶을 때만 필요합니다.
  (폴더만 연결해 읽기/검색만 할 거면 이 단계는 건너뛰어도 됩니다)
  1. Obsidian 실행 → 설정(톱니) → 커뮤니티 플러그인 → 탐색
  2. "Local REST API" 검색 → 설치 → 사용(Enable)
  3. 플러그인 설정에서 "API Key" 를 복사
  4. [설정] → Obsidian 연동:
     - "Obsidian 저장 사용" 켜기
     - "Local REST API 주소" (기본 https://127.0.0.1:27124)
     - "Local REST API 키" 붙여넣기
  공식 안내: https://github.com/coddingtonbear/obsidian-local-rest-api


########################################################
3. 기능 사용법
########################################################

- [업로드]   : 녹음 파일(mp3/m4a/wav/mp4 등) → 자동 회의록
    · 처리 순서: 음성 인식 → STT 교정(오탈자·고유명사 정리) → (번역 켜면)
      한국어 번역 → 번역 검수(원문과 대조해 오역·누락 교정) → 회의록/요약.
      번역을 켜면 원문 그대로 교정한 뒤 번역하므로 결과가 더 정확합니다.
    · 마이크 입력이 작거나 들쭉날쭉한 녹음은 자동으로 음량을 고르게 맞춰
      인식률을 높입니다([설정]→고급 설정→"오디오 전처리"에서 조절).
- [녹음]     : 마이크로 실시간 녹음/전사
    · 말하면 몇 초 안에 "흐린 글씨"로 임시 전사가 먼저 뜨고, 약 25초마다
      그 구간을 다시 정밀 전사해 온전한 문장으로 바꿔 줍니다(글씨가 선명해짐).
      화면의 문장이 잠시 뒤 바뀌는 것은 오류가 아니라 정상 동작입니다.
      회의록은 항상 보정된(선명한) 문장 기준으로 만들어집니다.
      ([설정]→실시간 녹취→"2단계 전사 보정"에서 끌 수 있습니다)
    · "안녕하세요" 한 마디처럼 내용이 너무 짧으면 회의록을 만들지 않고
      전사 기록만 저장합니다(대시보드가 빈 회의록으로 지저분해지지 않도록).
    · 전사가 쌓이면 그 영역 안에서만 스크롤됩니다. 위로 올려 읽는 동안에는
      자동 스크롤이 멈추고 "최신 전사로" 버튼이 뜹니다(누르면 맨 아래로).
    · [불명] 표시가 붙은 줄은 음성인식이 잘못 만들어낸 구간입니다(주로 무음·
      잡음 구간). 회의록에는 반영되지 않으니 그대로 두면 됩니다.
    · ★ 한국어 회의인데 엉뚱한 외국어가 섞이거나 같은 문장이 반복되면:
      [설정]→실시간 녹취→"기본 언어"가 ko(한국어)인지 확인하고, 녹음 시작
      화면의 모드를 "한국어 회의"로 두세요. 그래도 이상하면 마이크가 멀리
      있을 가능성이 큽니다(노트북을 말하는 사람 쪽·회의실 중앙에 두세요).
      목소리가 작아 전사가 잘게 끊기면 [설정]→실시간 녹취→"무음 판정
      임계값(RMS)"을 100~200으로 낮추세요.
- [텍스트 분석]: 이미 있는 회의 메모/전사 텍스트 → 회의록으로 정리
- [위키 질문]: 볼트(.md)에 쌓인 회의·세미나 기록을 근거로 질문 답변
- [회의 준비]: 제목/주제로 관련 노트·이전 결정·미완료 액션을 모아 준비자료
- [회의 비서]: 볼트의 회의 일정·현황 요약, 일정 대시보드 갱신, 녹음↔계획 병합,
    노트에 첨부된 녹음 자동 처리, "계획 자동화"(planned 노트 사전 리서치 + 첨부 녹음
    자동 처리) 시작/중지. (Obsidian 볼트 폴더가 [설정]에 지정돼 있어야 동작)
- [지식그래프]: 회의·인물·프로젝트·주제가 어떻게 연결됐는지 검색·탐색
- [대시보드] : 지금까지 만든 회의록 목록·상세 보기 (문서 복사/다운로드/재생성)
- [설정]     : 키·폴더·모델·기능 토글을 언제든 변경
    · [설정]→"폴더 자동 감시": 지정한 폴더에 새 녹음 파일이 생기면 자동으로
      회의록을 만들어 줍니다. 카드의 [폴더 추가]로 감시할 폴더를 고른 뒤
      [감시 시작]을 누르세요. (폴더를 바꾸면 [감시 중지] 후 다시 시작)
    · Slack/Teams 알림: [설정]→"고급 설정"→"알림"에서 Webhook URL 을 입력하고
      "완료 알림 채널"을 slack/teams 로 바꾸면 처리 완료 시 알림이 갑니다.

모델 선택([설정]→모델)은 드롭다운에서 고르며, 각 모델의 특징과
대략적인 비용이 함께 표시됩니다. 잘 모르겠으면 기본값을 그대로 두세요.


########################################################
4. 프로그램 업데이트 방법
########################################################

새 버전(MeetingMinutesPortable.zip)을 받으면:

  1. 실행 중이면 웹 [설정] → "앱 종료" 로 프로그램을 종료합니다.
  2. ★ 중요: 기존 폴더의 "MeetingMinutesData" 폴더를 안전한 곳에
     복사(백업)해 둡니다. (여기에 설정과 회의록이 들어 있습니다)
  3. 새 zip 을 새 폴더에 풉니다.
  4. 백업해 둔 "MeetingMinutesData" 폴더를 새 폴더(MeetingMinutes.bat 옆)로
     통째로 옮깁니다. → 설정(키 포함)과 회의록이 그대로 이어집니다.
  5. 새 "MeetingMinutes.bat" 를 실행합니다.
     - 설정 구조가 바뀌었어도 실행 시 자동으로 맞춰집니다(마이그레이션).

  ※ 같은 폴더에 덮어쓰기로 업데이트해도 MeetingMinutesData 를 그대로 두면
     설정/회의록은 유지됩니다. 다만 위 백업 방식을 권장합니다.


########################################################
5. 내 데이터는 어디에 저장되나요?
########################################################

MeetingMinutes.bat 옆 "MeetingMinutesData" 폴더:
  ├─ config.json   ... 내 설정(키 포함)
  ├─ output\       ... 생성된 회의록/요약 파일
  ├─ data\         ... 인덱스/DB/로그 (오류 로그: data\logs\web_exe.log)
  └─ web\          ... 업로드 파일, 세션 DB

※ "app" 폴더와 "python-embed" 폴더는 프로그램 본체입니다. 건드리지 마세요.
  (내 데이터는 위 MeetingMinutesData 에만 저장됩니다)


########################################################
6. 문제가 있을 때
########################################################

- 실행해도 아무 반응이 없음 / 브라우저가 안 열림:
  "Troubleshoot.bat"(문제 진단용 콘솔) 을 더블클릭하세요. 검은 창에 오류가 그대로 보입니다.

- 실행이 막힘 / "Windows의 PC 보호(SmartScreen)" 또는 보안 경고가 뜸:
  사내망/인터넷으로 받은 zip의 "차단" 표식 때문입니다. 압축 푼 폴더를 지우고,
  zip 파일 우클릭 → 속성 → 하단 "차단 해제" 체크 → [확인] 후 다시 압축을 푸세요.
  경고 창이 떠도 "추가 정보 → 실행"으로 진행할 수 있습니다.

- "ffmpeg가 없습니다" 경고:
  오디오 변환 도구가 없어 업로드 처리가 안 될 수 있습니다.
  app\vendor\ffmpeg\ 에 ffmpeg.exe 가 있는지 확인하거나
  배포 담당자에게 ffmpeg 포함 버전을 요청하세요.

- 회의록 생성 실패:
  대시보드에서 실패한 세션을 열면 빨간 글씨로 실패 원인이 표시됩니다.
  [설정]에서 OpenAI(또는 Claude) 연결 테스트가 "성공"인지 확인.
  키 만료/결제 미설정이면 실패합니다.
  ※ 음성 인식만 계속 실패한다면 위 "(2-1) 음성 인식이 멈추지 않게 하는 백업"의
    Groq 키를 넣어 두세요. 다음부터는 실패한 구간이 자동으로 대체 전사됩니다.

- "로컬 STT 최종 백업"을 켰는데 안 쓰이는 것 같음:
  모델 가중치를 준비하지 않으면 이 단계는 조용히 건너뛰어집니다(회의 처리 도중에 큰
  파일을 내려받지 않도록 일부러 막아 둔 동작). [설정] → 고급 설정 → 오디오 전처리 →
  [로컬 백업 모델 준비] 를 한 번 누르면 버튼 옆에 "준비됨" 으로 표시됩니다.
  또한 이 백업은 파일 업로드·폴더 감시에만 적용됩니다(실시간 녹음 제외).

- 실시간 녹음이 끝났는데 "음성 인식 호출이 N회 실패해 저장할 내용이 없습니다":
  마이크 문제가 아닙니다. 인터넷·API 키·사내망 차단을 확인하세요.
  Groq 키를 넣어 두면 이런 구간이 자동으로 대체 전사됩니다(위 2-1 참고).
  인터넷이 아예 끊긴 자리에서는 실시간 녹음 대신 다른 기기로 녹음한 파일을
  나중에 올려서 처리하세요(그 경로는 이 PC 안에서 도는 백업까지 씁니다).

- 위키/회의준비가 결과를 못 찾음:
  [설정]에서 Obsidian 볼트 폴더가 맞는지 확인하고 [검색 인덱스·그래프 재빌드]를
  눌러 최신화하세요.

- [지식그래프]에 회의가 아닌 것(발표자료.pptx, 원본파일 폴더의 파일 등)이 보임:
  [설정] → [검색 인덱스·그래프 재빌드] 를 한 번 누르면 정리됩니다. 위키 검색이
  노트로 보지 않는 파일은 그래프에서도 빼도록 바뀌었는데, 예전에 만들어진
  항목은 재빌드할 때 함께 정리됩니다.

- 그 외 오류:
  MeetingMinutesData\data\logs\web_exe.log (및 같은 폴더의 다른 로그) 파일을
  담당자에게 전달해 주세요. (콘솔 창이 없으므로 오류는 이 로그에 기록됩니다)
