# 회의 비서 사용 설명서 (USER GUIDE)

> **이 문서는 비개발자용 기능·사용법의 상세 안내서입니다.**
> **설치·실행 절차의 정본(single source of truth)은 배포본에 동봉된 `사용법.txt`**
> (저장소: [`../scripts/build/사용법_포터블.txt`](../scripts/build/사용법_포터블.txt))**입니다.**
> 이 문서와 앱 내 [도움말] 화면은 그 설치 안내를 기준으로 동기화하며, 여기서는 설치 요약과 함께
> 각 기능의 자세한 사용법을 다룹니다.
> (개발자용 개요·CLI·아키텍처는 [`../README.md`](../README.md), [`ARCHITECTURE.md`](ARCHITECTURE.md) 참고.)

회의/세미나 오디오를 자동으로 글로 옮기고(음성인식), **회의록·요약·액션아이템**을 만들어 줍니다.
원하면 Obsidian 볼트(.md 폴더)에 정리해 쌓고, 지난 기록을 근거로 질문하거나(위키) 회의 준비 브리핑을 만들 수 있습니다.

> **아이폰/아이패드 앱**으로도 쓸 수 있습니다(단독 모드 또는 같은 WiFi의 PC에 연결하는 "PC 연결 모드").
> 빌드·사용법은 [`../scripts/build/iOS_빌드_사용법.md`](../scripts/build/iOS_빌드_사용법.md) 참고. (빌드는 Mac 필요)

## 1. 설치와 실행 (포터블 배포본)

> 자세한 설치 안내는 배포본에 동봉된 **`사용법.txt`**(정본)를 따르세요. 아래는 요약입니다.

1. 받은 **`MeetingMinutesPortable.zip`** 을 원하는 폴더에 **전부** 풉니다. (예: `바탕화면\MeetingMinutes`)
2. 폴더 안의 **`MeetingMinutes.bat`** 를 더블클릭합니다. (별도 파이썬 설치 불필요 — 파이썬이 함께 들어 있습니다)
3. 잠시 뒤(처음엔 20~40초) 웹 브라우저가 자동으로 열립니다. 검은 콘솔 창은 뜨지 않습니다(`pythonw` 백그라운드 실행).
   - 안 열리면 브라우저에 `http://localhost:8501` 을 입력하세요.
   - **8501이 이미 쓰이는 중이면 자동으로 다른 포트를 선택**하므로 주소가 다를 수 있습니다. 이때는 자동으로 열린 창을 쓰거나 종료 후 다시 실행하세요.
4. 종료: 웹 화면 [설정] → 맨 아래 **"앱 종료"** (또는 작업 관리자에서 `pythonw` 프로세스 종료).

> 실행이 안 되거나 오류를 확인하려면 폴더의 **`Troubleshoot.bat`** 를 실행하세요(콘솔 창으로 진단 메시지를 보여줍니다).
> 백신(SmartScreen 등) 경고가 나오면 폴더를 신뢰 목록에 추가하거나 배포 담당자에게 문의하세요. `.bat`/포터블 파이썬 방식이라 서명되지 않은 단일 exe보다 경고가 적습니다.

## 2. 처음 한 번만: API 키 설정

처음 실행하면 **설정 마법사**가 자동으로 뜹니다. 순서대로 넣으면 준비 끝입니다.

| 순서 | 항목 | 필수? | 비고 |
|---|---|---|---|
| ① | **OpenAI API 키** | **필수** | 음성인식 + 회의록 생성. 기본 AI가 OpenAI라 이 키만 있으면 바로 시작 |
| ② | 결과 저장 폴더 | 권장 | 미지정 시 `MeetingMinutesData\output\` 에 저장 |
| ③ | Obsidian 볼트 폴더 | 선택 | 회의록을 .md로 쌓고 위키·회의준비를 쓰려면 |
| ④ | 이메일/Slack/Teams | 선택 | 완료 알림. **기본은 꺼짐** — 쓰려면 설정 후 채널 선택 |

- **OpenAI 키 발급**: <https://platform.openai.com/api-keys> → [+ Create new secret key] → `sk-proj-...` 복사(한 번만 표시) → [설정]에 붙여넣기 → [설정 저장] → [OpenAI 연결 테스트]로 확인. (결제수단 등록 필요할 수 있음. 회의 1건 보통 수백 원.)
- **Claude(선택)**: 회의록 AI를 Claude로 바꾸려면 <https://console.anthropic.com/settings/keys> 에서 `sk-ant-...` 발급 → [설정]에 입력 → [설정]→모델→"회의록 생성 AI"를 **Claude**로 변경. (기본은 OpenAI(GPT)라 이 단계는 건너뛰어도 됩니다.)

입력한 키는 이 PC의 `config.json`에만 저장되고 화면엔 ●●●로 가려집니다.

## 3. 기능

| 메뉴 | 하는 일 |
|---|---|
| **업로드** | 녹음 파일(mp3/m4a/wav/mp4 등) → 자동 회의록. 처리 중 **취소** 가능 |
| **녹음** | 마이크로 실시간 녹음/전사 (실시간 화면엔 화자 구분이 안 나올 수 있음 — 아래 참고) |
| **텍스트 분석** | 이미 있는 회의 메모/전사 텍스트 → 회의록으로 정리 |
| **대시보드** | 지금까지 만든 회의록 목록·검색·삭제. 클릭하면 상세(복사/다운로드/메일 공유/**메모 넣어 재생성**) |
| **설정** | 키·폴더·모델·기능 토글, 폴더 자동 감시, 알림 |
| 위키 질문 / 회의 준비 / 회의 비서 / 지식그래프 | Obsidian 볼트 폴더를 지정하면 활성화 |

**모델 선택**([설정]→모델)은 드롭다운에서 고르며 특징·대략 비용이 함께 표시됩니다. 잘 모르겠으면 기본값을 그대로 두세요.

> 앱 안에서도 이 내용을 **[도움말]** 화면에서 그림처럼 단계별로 볼 수 있습니다. 설정이 헷갈리면 [도움말] 위쪽 **[설정 마법사 다시 열기]** 를 누르면 필요한 것만 순서대로 다시 물어봅니다.

### 만든 회의록 고치기 · 메일 보내기
[대시보드]에서 회의록을 클릭하면 상세 화면이 열립니다.
- **문서 탭**: 회의록 · 요약 · 스크립트(시간·화자별 전사) · 액션 · (노트 폴더 연동 시) 사실확인 · 위키 맥락/제안 · 정제본 · 그래프. 문서가 없는 탭은 자동으로 숨겨집니다.
- **복사 / 다운로드 / 공유**: 오른쪽 위 버튼. **공유**는 메일·메신저로 보냅니다(본문이 길면 앞부분만 실리니 전문은 **다운로드**해 첨부).
- **메모(지시) 넣어 다시 만들기 — 재생성**: **회의록** 또는 **요약** 탭 아래쪽 "노트 반영해 재생성" 칸에 지시를 적고(예: "액션 아이템을 표로 정리해줘") **[AI 문서 재생성]** 을 누르면, 음성 인식은 다시 하지 않고(빠르고 저렴) 지시를 반영해 다시 작성합니다. 여러 번 반복해도 원본 전사는 유지됩니다.

### 메일로 보내기 (2가지)
- **방법 A(간단)**: 상세 화면에서 문서를 열고 **[공유]** → 메일 앱에서 받는 사람 넣고 전송.
- **방법 B(자동)**: [설정]→이메일에 **보내는 주소·앱 비밀번호·받는 주소**를 넣고 **[테스트 메일 보내기]** 로 확인. 실시간 녹음은 [설정]→실시간 녹취→"종료 후 이메일 자동발송"을 켜면 끝나는 즉시 메일이 옵니다.
  - 주의: 로그인 비밀번호가 아니라 메일 서비스에서 발급하는 **'앱 비밀번호'** 입니다. (Gmail: 2단계 인증 후 발급 / 네이버: POP3·SMTP 설정 / 아웃룩·회사메일: 계정 보안→앱 암호, 막혀 있으면 IT에 SMTP 허용 요청)

### 전사에 엉뚱한 외국어·같은 문장 반복이 섞일 때
음성인식 모델은 **소리가 거의 없는 구간**을 전사하라고 하면 없는 말을 만들어냅니다
(러시아어 조각, 같은 문장 반복 등). 이 앱은 기본적으로 다음을 막아 둡니다.

- 발화가 없는 구간은 아예 전사하지 않음 ([설정]→실시간 녹취→**무음 구간 전사 건너뛰기**)
- 직전 전사 문장을 모델에 다시 넣지 않음 ([설정]→**전사 문맥 전달 방식** = `static`)
- 되풀이 문장은 한 번으로 축약, 회의 언어에 없는 문자는 `[불명]` 표시
  ([설정]→**환각·반복 자동 정화**)
- [설정]→실시간 녹취→**기본 언어**는 회의 언어로 직접 지정하세요. `auto`는 짧은 조각마다
  언어를 다시 판정해 잘못된 언어로 전사될 수 있어 권장하지 않습니다.

그래도 반복·환각이 보이면 **오디오 품질**이 원인일 가능성이 큽니다.
마이크(노트북)를 말하는 사람 쪽·회의실 중앙에 두고, 스피커폰과 너무 가까우면 피하세요.
목소리가 작아 전사가 잘게 끊기면 [설정]→실시간 녹취→**무음 판정 임계값(RMS)** 을
100~200으로 낮추세요(반대로 시끄러운 회의실이면 500~800으로 올립니다).

### 상대방 목소리가 안 들어올 때 — 「소리 잡는 방법」

녹음 화면 세션 설정의 **소리 잡는 방법**에서 지금 상황을 고르세요. 마이크 설정이 상황마다
정반대로 필요해서(근접 발화엔 에코 취소가 이롭고, 멀리서 나는 스피커 소리엔 그 에코 취소가
바로 그 소리를 지웁니다) 하나를 고르는 방식입니다.

| 선택 | 언제 |
|---|---|
| **내 마이크만** (기본) | 대면 회의·헤드셋으로 내가 말하는 경우 |
| **내 마이크 + 이 PC 소리** | Teams 등 **온라인 회의를 헤드셋으로** 할 때. 헤드셋을 쓰면 상대 목소리가 마이크에 안 잡혀 기록이 절반만 남습니다 |
| **회의실 마이크 (멀리 있는 소리)** | **TV·스피커폰**으로 상대 목소리가 나오는 회의실. 에코 취소를 끄고 마이크 감도를 올립니다 |

**[내 마이크 + 이 PC 소리]를 고르면** 녹음 시작 직후 브라우저 공유 창이 뜹니다 —
**[전체 화면]을 고르고 아래 [시스템 오디오도 공유]를 꼭 켜세요.** 화면은 녹화되지 않고
소리만 씁니다. 오디오를 켜지 않았거나 도중에 [공유 중지]를 누르면 화면 위쪽에 안내가 뜨고
그때부터는 마이크만 녹음됩니다.

> iPhone/iPad 앱에서는 이 선택지가 보이지 않습니다(브라우저 화면공유 API가 없음).

### "누가 말했는지"(화자 분리)
- **파일 업로드**: [설정]→모델→음성인식을 `gpt-4o-transcribe-diarize`로 바꾸면 화자 라벨이 채워집니다.
- **실시간 녹음**: 실시간 화면엔 화자가 안 나옵니다. 필요하면 [설정]→고급(전체 JSON 편집)에서 `realtime.diarize_postprocess`를 `true`로 켜세요 — 녹음 종료 후 다시 전사해 화자를 채웁니다(시간·비용이 조금 더 듭니다). (친절한 설정 화면엔 별도 토글이 없고 JSON 키로만 조정)

## 4. 내 데이터 위치

프로그램 폴더(`MeetingMinutes.bat` 옆) 안의 **`MeetingMinutesData`** 폴더에 모두 저장됩니다.

```
MeetingMinutesData\
 ├─ config.json   ... 내 설정(키 포함) — 공유 금지
 ├─ output\       ... 생성된 회의록/요약 파일
 ├─ data\         ... 인덱스/DB/로그
 └─ web\          ... 업로드 파일, 세션 DB
```

> ⚠️ `config.json`에는 API 키·이메일 비밀번호가 **평문**으로 들어 있습니다. 이 폴더/파일을 그대로 남에게 전달하지 마세요.

## 5. 업데이트

1. 실행 중이면 [설정]→"앱 종료"로 종료.
2. **기존 `MeetingMinutesData` 폴더를 백업**(설정·회의록이 들어 있음).
3. 새 `MeetingMinutesPortable.zip`을 **새 폴더**에 풀고, 백업한 `MeetingMinutesData`를 새 폴더(`MeetingMinutes.bat` 옆)로 옮깁니다.
4. 새 `MeetingMinutes.bat` 실행 — 설정 구조가 바뀌었어도 자동으로 맞춰집니다(마이그레이션).

## 6. 문제가 있을 때

- **"ffmpeg가 없습니다"**: 오디오 변환 도구 누락. 폴더의 `vendor\ffmpeg\`에 `ffmpeg.exe`를 넣거나 배포 담당자에게 ffmpeg 포함 버전 요청.
- **회의록 생성 실패**: [설정]에서 OpenAI(또는 Claude) 연결 테스트가 "성공"인지 확인. 키 만료/결제 미설정이면 실패.
- **회사/학교망 SSL 오류**: [설정]→고급→"SSL 인증서 검증"을 끄세요(기본은 켜짐 권장 — 끄면 MITM 위험).
- **위키/회의준비가 결과를 못 찾음**: [설정]에서 Obsidian 볼트 폴더 확인 후 [검색 인덱스 재빌드].
- **그 외 오류**: `MeetingMinutesData\data\logs\web_exe.log`를 담당자에게 전달(콘솔 창이 없어 오류는 이 로그에 기록됩니다).
