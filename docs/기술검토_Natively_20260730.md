# 기술 검토 — Natively (오픈소스 회의 어시스턴트)

- 조사일: 2026-07-30
- 출처: https://github.com/Natively-AI-assistant/natively-cluely-ai-assistant (⭐ 약 874)
- 성격: Electron + Rust 데스크톱 앱. 실시간 전사·AI 회의록·로컬 RAG·BYOK를 무료로 제공하고,
  동시에 **"완전히 탐지 불가"한 스텔스 모드**(독 숨김·프로세스 위장·화면공유 회피)를 기능으로 홍보.

## 결론

**앞선 것은 오디오 입력 계층 하나뿐**이었고, 그 갭이 우리 실사용 문제(온라인 회의 상대 목소리
누락, 회의실 TV·스피커폰 소리 미수음)와 뿌리가 같아 그것만 가져왔다.
→ 커밋 `ceb5d92` (소리 잡는 방법 3택), `0c28713` (녹음 고지 안내).

## 불채택 근거 (자세히)

### 스텔스 모드
사내 회의 녹취는 **고지·동의**가 전제다. 탐지 회피 기능은 그 전제와 정면 충돌하므로 만들지
않는다. 대신 반대 방향으로 **녹음 전 화면에 참석자 고지 안내**를 넣었다(커밋 `0c28713`).
사내 AI 도구 가이드에 "회의 녹취·전사 도구는 사전 고지·승인 대상"이 있는지 확인할 계기로 쓸 수 있다.

### VAD(webrtcvad) 웹 경로 이식 — **이번엔 안 함**
VAD가 푸는 문제는 **오탐**(타이핑·팬 소음을 발화로 판정 → 불필요한 STT 과금·환각)이고,
이번에 우리가 푸는 문제는 **미탐**(작은 원거리 소리가 무음으로 버려짐)이다. 게다가 webrtcvad는
저SNR 원거리 음성에 약해 **원거리 발화를 더 버린다** — 목표와 상쇄된다. 임계값을 낮추면서 동시에
VAD로 조이면 두 장치가 서로를 지우고, 어느 쪽이 효과였는지 분리할 수도 없다.
(로직 자체는 CLI에 이미 있다 — `realtime_transcription.py: VADAudioRecorder`.)
오탐·과금이 실제로 관측되면 그때 **기본 꺼짐 옵션**으로 별건 진행.

### 적응형 무음 임계값 / 실시간 청크 게인 정규화 — **이번엔 안 함**
브라우저 `autoGainControl`을 켜는 것으로 같은 효과를 기대할 수 있다(레벨이 오르면 RMS 문턱도
자연히 넘고, 저음량 wav 문제도 함께 줄어든다). 상류 원인 하나를 고치면 증상 셋이 같이 사라질 수
있는데 증상마다 기계를 미리 붙이면 조잡해지고 효과를 분리할 수 없다.

**측정 방법(새 도구 불필요)**: 회의실에서 [회의실 마이크]로 한 번 녹음하고 종료 시 서버 로그의
`[http-stt] 환각 방어: 무음 청크 N개(M초) 건너뜀`(`web/backend/api/realtime.py`)과 빈 전사 청크
수(`_stt_empty_chunks`)를 이전 녹음과 비교한다. 그래도 발화가 버려지고 있으면 **가장 작은 수단부터**:
녹음별 설정 전달 경로(`stt_model` 오버라이드와 같은 방식)로 캡처 모드를 서버에 알려
`realtime.silence_rms`만 낮춘다 — 새 설정 키 0개, 새 알고리즘 0개.

### 채널별 화자 라벨(나/상대)
시스템 오디오와 마이크를 **분리된 두 STT 스트림**으로 보내면 화자 구분이 공짜로 생기지만
과금이 2배가 되어 비용통제 설계와 충돌한다. 단일 믹스로 간다. RMS 비교로 채널을 추정하는
휴리스틱도 실측 없이는 넣지 않는다.

## 설계 메모

초안에서는 원거리 대응을 "증상별 장치 3개(적응형 임계값·게인 정규화·VAD) + UI 2컨트롤"로 잡았다.
그 UI는 체크박스×셀렉터라 6조합이 되고 그중 모순 조합("시스템 소리 ON + 회의실 모드")에 경고
문구를 달아야 했다 — **경고를 달아야 한다는 것 자체가 설계가 틀렸다는 신호**였다.
상호배타 3택으로 합치니 모순 조합이 사라지고 경고도 필요 없어졌다.

## 후속

**회의 자료(PDF/PPTX/DOCX) 위키 인덱싱** — `vault_indexer.py`의 그림자 사본 규칙이 이 확장자를
제외해서 회의 자료 원문이 지식순환에서 빠져 있다. Natively의 "Reference Files" 에 해당하는 갭이며
별건으로 진행한다(pypdf 등 의존성 + 임베딩 비용 + `reindex` 필요).
