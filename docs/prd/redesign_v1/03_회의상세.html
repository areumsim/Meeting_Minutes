1. 회의 개요

IBM 파트너십 킥오프. 양자 SW 스택 로드맵과 큐비트 라우팅 협업 범위를 검토했다. 참석자는 심아름, 김영희, 이철수 외 IBM측 2인.

2. 주요 논의

  • 큐비트 구현 4방식(초전도·이온트랩·광자·중성원자)의 확장성 및 게이트 연산 속도 트레이드오프를 공유.
  • 초전도(IBM) 우선 채택 방향에 공감대 형성 — 근거 [[회사_파트너_위키]]의 파트너 현황과 사내 인프라 정합성.
  • RL 기반 큐비트 라우팅(Pozzi 2020)의 사내 PoC 재현 필요성 제기, 재현 범위와 데이터셋 논의.
  • 메가존/LG CNS 협업안은 클라우드 백엔드 관점에서 별도 트랙으로 검토키로.

3. 결정 사항

  • Q3 내 초전도 우선 로드맵 확정.
  • RL 라우팅 PoC 8월 착수, 담당 심아름.
  • 메가존/LG CNS 협업안 초안 작성 후 재검토.

4. 다음 회의

2주 후 중간 점검 — PoC 초기 결과와 파트너 NDA 상태 공유.

요약

IBM과 초전도 큐비트 우선 로드맵에 합의. RL 라우팅 PoC 재현을 8월 내 착수(담당 심아름). 메가존/LG CNS 협업은 별도 트랙으로 검토. 2주 후 중간 점검.
