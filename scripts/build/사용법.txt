========================================
  회의록 자동 생성기 (Meeting Minutes)
  사용 설명서
========================================

이 프로그램은 회의/세미나 오디오를 자동으로 글로 옮기고(STT),
회의록·요약·액션아이템을 만들어 줍니다. 원하면 Obsidian 볼트에도 저장합니다.


----------------------------------------
1. 실행 방법
----------------------------------------

1) 받은 압축파일(MeetingMinutes.zip)을 원하는 폴더에 전부 풉니다.
   (예: 바탕화면\MeetingMinutes)

2) 폴더 안의 "MeetingMinutes.exe" 를 더블클릭합니다.

3) 검은색 창(콘솔)이 뜨고, 잠시 뒤 웹 브라우저가 자동으로 열립니다.
   - 브라우저가 안 열리면 콘솔에 표시된 주소(예: http://127.0.0.1:8501)를
     직접 브라우저 주소창에 입력하세요.

4) 프로그램을 끄려면 그 검은색 창을 닫으면 됩니다.

   ※ 검은색 창은 프로그램 본체입니다. 창을 닫으면 프로그램도 꺼집니다.


----------------------------------------
2. 최초 설정 (처음 한 번만)
----------------------------------------

처음 실행하면 [설정] 화면으로 자동 이동합니다. 아래 두 가지를 입력하세요.

  (1) OpenAI API 키  ← 필수
      - "sk-..." 로 시작하는 키를 붙여넣습니다.
      - 음성 인식과 회의록 생성에 사용됩니다.

  (2) Obsidian 볼트 폴더  ← Obsidian을 쓰는 경우
      - 회의록을 저장할 Obsidian 볼트 폴더 경로를 넣습니다.
        (예: D:\Obsidian\MyVault)
      - Obsidian을 안 쓰면 비워 두어도 됩니다. 이때는 결과가
        데이터 폴더의 output 안에 파일로만 저장됩니다.

입력 후 [설정 저장]을 누르고, [OpenAI 연결 테스트] / [Obsidian 경로 확인]
버튼으로 제대로 되었는지 확인할 수 있습니다.

  ※ 입력한 키는 이 PC 안에만 저장되며(config.json), 화면에서는 가려져 보입니다.


----------------------------------------
3. 사용하기
----------------------------------------

- [업로드] : 녹음 파일(mp3, m4a, wav, mp4 등)을 올리면 자동 처리됩니다.
- [녹음]   : 마이크로 실시간 녹음/전사를 합니다.
- [대시보드]: 지금까지 만든 회의록 목록을 봅니다.
- [설정]   : 키, 폴더, 기능 켜고 끄기 등을 언제든 바꿀 수 있습니다.


----------------------------------------
4. 내 데이터는 어디에 저장되나요?
----------------------------------------

프로그램(exe) 옆에 자동으로 만들어지는 "MeetingMinutesData" 폴더에 저장됩니다.

  MeetingMinutesData\
    ├─ config.json      ... 내 설정(키 포함)
    ├─ output\          ... 생성된 회의록/요약 파일
    ├─ data\            ... 인덱스/데이터베이스/로그
    └─ web\             ... 업로드한 파일, 세션 DB

프로그램을 다른 곳으로 옮기고 싶으면 exe 폴더와 이 데이터 폴더를 함께 옮기세요.
프로그램을 새 버전으로 교체할 때 이 데이터 폴더를 그대로 두면 설정과 회의록이 유지됩니다.


----------------------------------------
5. "Windows의 PC 보호" 경고가 떠요 (SmartScreen)
----------------------------------------

처음 실행할 때 파란색 경고창이 나올 수 있습니다. 안전한 프로그램이지만
서명이 없어 나오는 경고입니다.

  1) [추가 정보] 를 클릭합니다.
  2) [실행] 버튼을 누릅니다.


----------------------------------------
6. 문제가 있을 때
----------------------------------------

- "ffmpeg가 없습니다" 경고가 뜨는 경우:
  오디오 변환 도구(ffmpeg)가 없어서 업로드 처리가 안 될 수 있습니다.
  프로그램 폴더의 vendor\ffmpeg\ 안에 ffmpeg.exe 를 넣어 주세요.
  (배포 담당자에게 ffmpeg 포함 버전을 요청하셔도 됩니다.)

- 회의록 생성이 실패하는 경우:
  [설정]에서 OpenAI 연결 테스트가 "성공"으로 나오는지 확인하세요.
  키가 만료되었거나 결제가 안 되어 있으면 실패합니다.

- 그 외 오류:
  검은색 콘솔 창에 나오는 메시지, 또는
  MeetingMinutesData\data\logs\ 안의 로그 파일을 담당자에게 전달해 주세요.
