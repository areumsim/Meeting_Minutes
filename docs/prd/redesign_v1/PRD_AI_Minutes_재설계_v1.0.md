## 1. 배경 · 문제 · 목표

### 1.1 배경
AI Minutes는 회의 캡처(녹음·업로드·텍스트) → 구조화(회의록·요약·액션) → 저장(Obsidian 볼트) → 검색·연결(위키 질문·지식그래프) → 준비·자동화(회의 준비·비서)까지 회의 지식의 전 주기를 덮는 Windows 데스크톱 앱이다. 엔진은 강력하나 UI가 "개발자용 내부 툴" 상태에 머물러 있다.

### 1.2 문제 (현행 UI)
- 상단 SSL 경고가 상시 노출되어 신뢰를 해친다.
- 내비 8개가 액션·뷰·워크플로우·설정을 평평하게 섞어 시작점이 불명확하고 기능이 중복 진입된다.
- 모델 ID·2패스·WS/HTTP·세션 ID·per-초 비용 등 구현 세부가 그대로 노출된다.
- 설정이 단일 무한 스크롤이라 온보딩이 불가능하다.
- 여백·버튼이 커서 노트북 한 화면에 안 들어온다.

### 1.3 목표
1. 회의 생애주기 기반으로 IA를 5영역으로 정리한다.
2. 노트북(1440×900·1366×768)에서 주요 작업이 스크롤 없이 들어오는 고밀도 레이아웃.
3. 관련 노트·근거·페르소나는 본문을 가리지 않는 우측 인스펙터로 통일.
4. 상태(녹음중·처리중·완료·오류·계획)를 색으로 즉시 구분.
5. 기술용어를 평문화하되 기능·표시는 100% 보존.
6. 첫 실행 사용자가 "OpenAI 키 1개"만으로 시작 가능.

### 1.4 비목표
- STT/LLM/인덱싱/그래프 백엔드 로직 변경, 신규 AI 기능 추가, 가격 정책 변경. (이번 범위 아님)
- 성능·정확도 저하 금지 — 재설계는 표현 계층에 한정한다.

## 3. 설계 원칙 (수용 기준의 근거)
1. **누락 0** — `기능_커버리지_매트릭스_v1.md`의 전 항목이 새 IA에 존재한다.
2. **성능 불변** — 표현 계층만 변경. 스트리밍·리렌더 최적화는 허용(체감 개선), 파이프라인 변경 금지.
3. **고밀도** — 기본 13px, 촘촘한 테이블/2-pane. 대형 풀폭 버튼·과한 여백 금지.
4. **우측 인스펙터** — 노트/근거/페르소나/맥락은 항상 우측 패널, 본문 오버레이 금지.
5. **상태 색** — 녹음중=red / 처리중=purple / 완료=green / 오류=red+✕ / 계획=gray.
6. **평문화** — 모델 ID·전송방식·2패스 등은 평문 라벨로. 기능·상태 표시는 유지.
7. **차분한 기본** — 라이브 개입(페르소나)은 접힌 칩이 기본, 소리·팝업·포커스 이동 없음.
8. **어디서나 시작** — 모든 화면 topbar에 "＋ 새 회의".

### 4.3 모바일 (iOS · Capacitor) / 태블릿
앱: `com.meetingminutes.app` · **"AI 회의록"** · Capacitor + WKWebView. iOS는 `http://localhost` 스킴으로 로드 → 같은 WiFi PC 백엔드(평문 http)와 OpenAI(https/wss 직접)가 모두 통한다(혼합 콘텐츠 회피). `allowNavigation`에 `*.openai.com`.

- **내비 — 하단 탭 4 + 중앙 FAB**: 라이브러리 · 지식 · **＋(새 회의, 중앙 FAB → 시트: 녹음/업로드/텍스트)** · 준비·비서 · 더보기(설정·도움말·PC 서버 연결). 회의 상세·녹음은 탭이 아니라 **풀스크린 push**.
- **우측 인스펙터 → 바텀시트**: 관련 노트·진행 도우미(팩트체커)를 하단 트리거 바("🔴 확인 필요 N · 관련 N ▲")로 올려 여는 시트로. 본문(전사·회의록)을 가리지 않는다. 상세의 참조 노트도 동일 패턴.
- **테이블 → 카드 리스트**(상태색은 카드 좌측 보더). **그래프 → 노드 칩 리스트** 기본. 넓은 탭바 → 가로 스크롤.
- **단독 vs PC 서버 연결**: 더보기/온보딩에 PC 서버 연결(주소 입력). 단독 모드는 OpenAI 직접 전사만 되고 **볼트 검색·페르소나·서버 회의록 생성이 없다** → 관련 노트/진행 도우미 시트는 "PC 서버 연결 시 사용 가능" 빈 상태로.
- **iOS 세부**: 노치·`safe-area-inset` 상/하, 홈 인디케이터 여백. `capacitor.config.ts`의 `ios.backgroundColor`·`StatusBar.style`은 **테마 따라 동적**(라이트=웜 페이퍼 `#f7f6f3`/StatusBar dark, 다크=미드나잇 `#0f1011`/StatusBar light). SplashScreen·Keyboard(resize body)·Share(mailto)·Haptics·KeepAwake 유지. 마이크는 localhost 보안 컨텍스트라 `getUserMedia` 정상.
- **iPad**: 데스크톱 사이드바 + 2-pane 유지.

## 5. 디자인 시스템 (한 곳에서 정의, 전 화면 공유)

### 5.1 토큰 (CSS custom properties — 원시 색 리터럴 금지)
**중립(웜 페이퍼)**: `--bg #f7f6f3` · `--surface #fff` · `--surface-2 #f4f2ee` · `--hover #f0ede7` · `--line #eae7e1` · `--line-strong #d8d3ca` · `--ink #1c1a17` · `--ink-2 #57534e` · `--ink-3 #8a8279`(≥12px 전용).
**액센트(유일)**: `--accent #0d9488`(틸/에메랄드) · hover `color-mix(in srgb, var(--accent) 82%, #000)` · weak `color-mix(in srgb, var(--accent) 14%, var(--surface))`. 링크·포커스·활성 내비·주요 액션에만.
**다크 모드**: 미드나잇 중립(`--bg #0f1011` · `--surface #17181a` · `--surface-2 #1d1f22` · `--line #2a2e33` · `--ink #f2f3f4` · `--ink-2 #c3c8d0` · `--ink-3 #8a8f98`) + 밝은 틸 액센트(`color-mix(var(--accent) 62%, white)` ≈ `#2dd4bf`). 라이트/다크 토글 제공, `--shadow` 은 다크에서 none(보더로 층위).
**브랜드 마크**: 로고는 중립(`--ink` 사각형 + 워드마크). 별도 브랜드 컬러 미사용 — 실제 로고 자산이 정해지면 교체.
**상태**: `--rec #da1e28 / --rec-bg #fff1f1`(녹음중, 점멸) · `--proc #8a3ffc / #f6f2ff`(처리중) · `--ok #198038 / #defbe6`(완료) · `--err #da1e28`(오류, ✕ 병용) · `--idle #6f6f6f / #f4f4f4`(계획/대기).
**보조 시스템색(정식 채택)**: `--warn #8a5200 / --warn-bg #fdf1de / --warn-line #f0d9a8`(미검증·번역됨·대체처리·준비미비·충돌) · `--persona #007d79 / #d9fbfb`(진행 도우미). *sky(2번째 파랑)는 폐기 → info 칩은 `--blue-weak`로 흡수(리뷰 P2-4).*
**엔티티 그래프 팔레트(상태·액센트와 충돌 금지, 색맹 안전)**: 조직/인물/주제/회의/노트/프로젝트 각 전용 hue. 두 그래프 렌더러(상세 그래프 탭·지식 그래프) 공유(리뷰 P2-3). *`--blue`/status hue 재사용 금지.*
**형태·레이아웃**: `--r 8px`(카드) · `--r-sm 6px`(컨트롤) · 배지 `--pill 999px` · `--rail 206px` · `--topbar-h 52px` · `--inspector-w 320px` · `--gap 12px`. 섀도는 **아주 옅게만**(`0 1px 2px rgba(28,26,23,.04)`, `0 6px 16px -10px rgba(28,26,23,.15)`); 다크에서는 보더로 대체. 라이브러리 행 좌측 컬러바 inset 유지.

### 5.2 타이포
- 폰트: `IBM Plex Sans KR`(제목·본문) + `IBM Plex Mono`(시간·비용·점수·자릿수 정렬, `tabular-nums`). 오프라인 배포 대비 폴백 `Malgun Gothic, system-ui`.
- 스케일: 본문 13px/1.5 · 캡션 11–12px · 화면 제목 14–15px/600 · 문서 h3 14.5px. 시맨틱 색 텍스트는 12px 미만 금지(리뷰 P2-7).

### 5.3 아이콘 (리뷰 P2-8)
- 단색 라인 아이콘 1세트(Carbon Icons 권장), `stroke:currentColor` 1.5px. 이모지를 기능 아이콘으로 쓰지 않는다(Windows OS별 렌더·SR 문제). 장식은 `aria-hidden`, 단독 라벨이면 `aria-label`.

### 5.4 캐노니컬 컴포넌트 (각 1회 정의)
AppShell(Sidebar+Topbar) · Button(primary/secondary(보더 ≥3:1)/danger/ghost/icon; md·sm≥24px; pri·danger hover 필수) · Tabs·SegmentedControl(ARIA tab + 방향키 로빙) · StatusPill·Tag · Toggle/Switch(네이티브·라벨·off상태 대비 ≥3:1·포커스링) · Field/Select(Carbon underline) · Inspector(단일 폭·접기 rail) · NoteCard · PersonaCard(접힌 pchip→펼침 pfull) · CostMeter+CostBreakdown(disclosure, mono) · DataTable(행=링크 시맨틱 + 카드 반응형) · Graph(공유 노드 렌더러 + 엔티티 팔레트 + 키보드 탐색 리스트) · Modal(focus trap·`role=dialog`·Esc).
**캐노니컬 화면 확정**: 녹음=recording_v4, 회의 상세=detail_v2, 라이브러리·새로만들기=v0.3. 초기 preview의 녹음/상세 표현은 폐기.

### 5.5 접근성 (원본 수준 보존 — 리뷰 P1·P2)
- 전 인터랙티브 요소 키보드 조작·`focus-visible` 링. 내비=`<a href>`/`<button>` + 활성 `aria-current="page"`.
- 토글=네이티브 `role="switch"`+`aria-checked`+라벨. 탭=`role=tab/tablist/tabpanel`+`aria-selected`.
- 실시간 영역 `aria-live`: 전사=`role=log aria-live=polite`, 비용·상태칩=`status`, 진행바=`role=progressbar`+`aria-valuenow`.
- 색 단독 신호 금지(색+아이콘+텍스트). 오류=✕, 리스크=아이콘+라벨.
- 최소 히트타깃 24×24(페르소나 레벨 스텝퍼·세그먼트 포함).
- `prefers-reduced-motion`에서 blink/waveform/pulse/scale 모두 정지.

## 6. 화면별 스펙

표기: FR = 기능 요구, AC = 수용 기준.

### 6.1 라이브러리
목적: 모든 세션의 허브. 레이아웃: 상단 비용 요약(접이식) → 툴바(검색·유형/상태 필터·새로고침·휴지통) → 데이터 테이블 → 더 보기.
- FR-LIB-1 리스트 컬럼: 제목(+부제), 유형, 상태(색 배지), 화자 수, 길이, 비용, 날짜, **행 동작**.
- FR-LIB-2 행 동작(호버 노출): 완료=휴지통; **오류=재시도+휴지통**; 처리중=처리취소; 계획=**이 계획으로 녹음/사전 리서치**; 녹음중=열기.
- FR-LIB-3 **2단계 삭제**: 휴지통(소프트)↔완전삭제(Windows 휴지통), 되돌리기, 전체 삭제. 휴지통 뷰(삭제일·복원·완전삭제). Undo 알림 토스트.
- FR-LIB-4 검색(300ms 디바운스, 한글 IME 안전), 유형/상태 필터, 5초 자동 새로고침(처리중 세션 존재 시), 더 보기 50개씩.
- FR-LIB-5 **비용 요약 카드**: 월 예상/한도 진행바·월별 바·유형별·세션밖 지출(otherByKind)·상위 회의·"실측보다 클 수 있음" 면책.
- FR-LIB-6 상태별 빈/오류/로딩: 0건 첫실행 빈 상태, 목록 로드 실패 alert+재시도, CLI 배지, 번역됨 배지, 오류상세 툴팁.
- AC: 6건이 1440×900에서 스크롤 없이 보인다. 오류 행에서 상세 오류 상태로 진입해 재시도할 수 있다. 기계 생성 세션명은 사용자에게 노출되지 않는다(사람이 읽는 제목/‘제목 없음’).

### 6.2 새로 만들기 (녹음/업로드/텍스트)
- FR-NEW-1 세그먼트 3: 실시간 녹음 / 파일 업로드 / 텍스트.

- AC: 과금이 시작되는 4개 진입점 모두 비용 확인을 거친다. 모델 ID가 이 화면에 노출되지 않는다.

### 6.3 녹음 (실시간) — 캐노니컬 recording_v4

- FR-REC-4 전사: 화자 라벨·2패스 임시(흐리게)→보정·**원문+번역 2열 + 토글(원문+번역/원문/번역)**·전사 N줄·[불명] 범례·자동스크롤·"최신 전사로"(안 본 N줄)·상태칩(소리감지/무음/PC소리/회의실).

- FR-REC-6 우측 인스펙터(탭 2, 한 번에 하나): **관련 노트**(📄/🎓/🌐 칩·근거 보기·이번 회의 끔·검색꺼짐/muted 상태) · **진행 도우미**(페르소나 카드).
- FR-REC-7 진행 도우미(**차분한 기본**): 카드=접힌 한 줄 칩, **팩트체커=상단 "확인 필요 N" 고정**. 펼침 시 본문·인용·근거(source 아이콘)·⚠미검증·⟲발화보기·✓확인·✕닫기·건당 비용. 중간요약(brief)=논점/결정/액션/미결. 하단: **예산 상태칩(blocked/capped/budget)·지금 점검 N(무료)·지금 정리(비용)·이번 회의 끔**.

- FR-REC-9 종료 후: 자동 회의록 생성 → 상세 이동; 음성 없음/짧음 처리; 취소=유휴; 화면꺼짐 방지·햅틱·14분 WS 회전은 비가시 유지.

### 6.4 회의 상세 — 캐노니컬 detail_v2

### 6.5 지식 (질문 + 그래프)
- FR-KNO-1 세그먼트: 질문 / 그래프.
- FR-KNO-2 질문(RAG): 볼트 미연결 게이트, 백엔드 게이트, 질의(Enter 전송·Shift+Enter·IME 가드), 히스토리(최신순), 답변, **⚠충돌/확인불가 배지**, 컨텍스트 노트(제목·헤딩·점수), 출처 필수.
- FR-KNO-3 그래프: 검색/상위노드, 타입별 색(엔티티 팔레트), 연결 개요 렌더, **드릴다운(스택·뒤로·닫기)·속성·관계별 이웃**, 빈/오류 상태, 위키링크·상세에서 진입(initialQuery). 노드=키보드 탐색 가능 리스트+`aria-label`.
- AC: 볼트 미연결/결과 없음/로딩/그래프 비활성 상태가 각각 정의돼 있다.

### 6.7 설정 (필수/자주/고급 + 검색)
스키마 원천: `meeting_minutes_app/common/config_schema.py` (`/api/config/schema`). tier 순서 = 표시 순서.
- FR-SET-1 3티어 아코디언 + **설정 검색**(라벨·설명·키 매칭 필터).

- FR-SET-3 페르소나 매트릭스: 프리셋(조용히/표준/적극)·레벨 0~5·캡/잠금(4·5 관리자 개방)·적용값·고위험 경고.
- FR-SET-4 도구/위험구역: 전체 설정 JSON 편집(파괴적 확인)·폴더 자동 감시 카드·처리 프로필(생성/삭제)·앱 종료·전체 휴지통·설정 마법사 다시 열기·모바일 PC 서버 연결.

- AC: 첫 실행 사용자는 "필수"의 키+폴더만 보면 시작할 수 있다. 어떤 설정이든 검색으로 도달한다. SSL은 기본 ON이며 상시 경고 배너가 없다.

## 14. 결정 완료 (v1.0 확정)
1. **팔레트 = 웜 페이퍼 + 틸/에메랄드 액센트 `#0d9488`** (인터랙션·포커스·활성·주요 액션). 8px 라운드 · 필(pill) 상태 배지 · 아주 옅은 섀도. **라이트/다크 토글** 제공(다크=미드나잇 + 밝은 틸). 로고/브랜드는 중립, 별도 브랜드 컬러 미사용(코오롱 레드는 상태색 레드와 충돌해 미채택) — 실제 로고 자산 정해지면 교체.
2. **재생성 = 회의록·요약 탭만.** 원본(`SessionDetail.tsx`)도 두 탭에서만 재생성을 노출했으므로 **기능 손실이 아니다.** 확정 유지.
3. **그룹 라벨 제거.** leaf 5에서는 구분선(설정 앞)만 둔다. "지식/운영" 헤더 미사용.
4. **topbar = 최소(제목 + ＋ 새 회의).** 글로벌 검색은 라이브러리에 있으므로 topbar에 중복 배치하지 않는다(상용 확장 시 알림·사용자 메뉴와 함께 재검토).
